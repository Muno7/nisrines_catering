# Nisrine's Kitchen – Client Project

Welcome to Nisrine's Kitchen – a web application developed for a local food business. This project enables users to explore a menu of home-cooked meals, place orders, and manage favorites. It was designed with non-technical users in mind, streamlining order processing through automated PDF receipts and WhatsApp redirection.

## Table of Contents

- [Features](#features)
- [Technologies Used](#technologies-used)
- [Installation](#installation)

## Features

- Browse an up-to-date menu of delicious home-cooked meals.
- Place orders seamlessly with an efficient, automated order process.
- Receive professional PDF receipts.
- Enjoy a user-friendly experience that caters to non-technical customers and fiting client needs by redirecting them to WhatsApp for order confirmations.
- Responsive design ensures smooth interaction on both mobile and desktop devices.

## Technologies Used

- **Frontend**: HTML, CSS, JavaScript, Tailwind CSS
- **Backend & Data Management**: Firebase (Storage & SDK), Google Sheets API, jsPDF, Google Maps API
- **Build Tool**: Vite (for development and production builds)
- **Scripting**: Python (for weekly product updates via `update_products.py`)

## Installation

To get started with the project, follow these steps:

1. Clone the repository:
   
```bash
   git clone https://github.com/Muno7/nisrines_kitchen.git
```

2. Navigate to the project directory:
   
```bash
   cd nisrines_kitchen
```

3. Install the dependencies:
   
```bash
   npm install
```

4. Start the development server:
   
```bash
   npm run dev
```

5. Open your browser and go to http://localhost:5173 or the provided link in the console to view the application.

6. For the python script:
```bash
 pip install requests
```
